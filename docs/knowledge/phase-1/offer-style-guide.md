# Offer Style Guide

Teklif taslagi su bolumleri ayri tutar:

- musteri baglami
- problem hipotezi
- onerilen kapsam
- teslimatlar
- kapsam disi maddeler
- varsayimlar
- guvenlik ve compliance notlari
- riskler
- sonraki adim

Dil net ama baglayici olmayan tonda olmalidir. Gonderime hazir degil, incelemeye hazir artifact uretilir.
